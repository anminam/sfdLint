# 변경 이력

## 1.1.0 (2026-11-02)

- 한 번 호출로 검사와 실패 처리를 수행하는 `checkFiles()` API 및 CommonJS/ESM 예제 추가.
- 주석·문서와 예제 설정 이름을 프로젝트 기준 표현으로 통일.
- 2026-10-21 Node.js 공식 보안 업데이트에 맞춰 지원 범위를 `^22.23.4 || ^24.22.1 || ^26.12.1`로 변경.
- 지원 종료된 Node.js 20/25 계열을 제외하고 권장 개발 버전 24.22.2를 `.nvmrc`에 기록.

## 1.0.0

- 파일 경로 배열을 받는 비동기 `lintFiles` API.
- CommonJS와 ESM 진입점, 기존 ESLint env/globals 설정 변환.
- 직렬화 가능한 검사 결과, 콘솔 포맷터, 파이프라인 중단용 assertion.
- ESLint 10.14.0과 의존성을 포함한 설치 없는 폴더 배포.
