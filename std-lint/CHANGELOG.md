# 변경 이력

## 2.2.2 (2026-11-04)

- HTML·텍스트 등 비 JavaScript 파일과 ESLint 제외 파일을 오류 대신 `status: 'ignored'`로 처리.
- 매칭 설정 없음 알림을 issues/errorFiles와 isError에서 제외. 실제 JavaScript 오류는 계속 보고.
- summary 필드 구조는 유지하며 무시한 파일은 전체 fileCount에만 포함.

## 2.2.1 (2026-11-03)

- 전용 JSON의 `errorMessage` 문자열을 `errorMessages` 문자열 배열로 변경.
- 문법·규칙·검사 실행 문제를 오류 하나당 배열 항목 하나로 제공. 경고 제외와 알림 후 빌드 진행 유지.

## 2.2.0 (2026-11-03)

- CLI `--format compact-json` 추가: 기존 메타·summary와 오류 파일만 모은 `report` 반환.
- 경고를 제외하고 파일별 오류를 줄바꿈으로 결합. 파일 읽기·설정 문제도 오류 알림에 포함.
- 전용 형식의 JSON 저장, 예시 및 스키마 제공. 알림 후 정상 종료 동작 유지.

## 2.1.0 (2026-11-03)

- `temp_files.txt`를 받는 CLI와 `npm run lint:notify` 진입점 추가.
- 쉼표·CR/LF·BOM·빈 항목·CSV 따옴표를 지원하는 목록 파서 추가.
- 목록·설정·경로 기준·JSON 출력/저장 옵션 및 riabuild/execSync 연결 문서 추가.
- 검사 위반과 목록·설정·의존성 문제도 알림 후 정상 종료하여 기존 빌드 진행 유지.

## 2.0.1 (2026-11-02)

- 기본 예제 설정을 `sourceType: 'module'`로 변경해 CJS 실행기에서 import/export 대상 코드 검사 지원.
- 실행기·설정 파일 형식과 검사 대상의 sourceType 차이 및 혼합 파일 설정 방법 문서화.
- import/export를 사용하는 실행 검증용 예제 파일 추가.

## 2.0.0 (2026-11-02)

- 알림 목적에 맞춰 `checkFiles()`를 변경: 문법·규칙 오류와 파일·설정 실패를 예외 대신 report로 반환.
- 모든 사용 예제에서 검사 결과에 따른 빌드 중단과 비정상 종료 코드 설정을 제거.
- `passed`와 `exitCode`는 검사 결과 분류로 유지하며 프로세스 진행 여부에 자동 적용하지 않음.
- 기존 `assertPassed()`도 report를 그대로 반환하는 호환 함수로 변경해 기존 연동 코드의 중단 방지. 새 코드에서는 사용하지 않음.

## 1.1.0 (2026-11-02)

- 한 번 호출로 검사와 실패 처리를 수행하는 `checkFiles()` API 및 CommonJS/ESM 예제 추가.
- 주석·문서와 예제 설정 이름을 프로젝트 기준 표현으로 통일.
- 2026-10-21 Node.js 공식 보안 업데이트에 맞춰 지원 범위를 `^22.23.4 || ^24.22.1 || ^26.12.1`로 변경.
- 지원 종료된 Node.js 20/25 계열을 제외하고 권장 개발 버전 24.22.2를 `.nvmrc`에 기록.

## 1.0.0

- 파일 경로 배열을 받는 비동기 `lintFiles` API.
- CommonJS와 ESM 진입점, 기존 ESLint env/globals 설정 변환.
- 직렬화 가능한 검사 결과, 콘솔 포맷터, 파이프라인 중단용 assertion.
- ESLint 10.14.0과 의존성을 포함한 설치 없는 폴더 배포.
